# Schemathesis GraphQL API

Schemathesis is a property-based API testing tool that automatically generates test cases from OpenAPI and GraphQL schemas to find bugs and spec violations. It detects server crashes, schema violations, validation bypasses, and integration failures with minimal maintenance overhead—tests adapt automatically as schemas evolve.
